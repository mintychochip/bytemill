# Third-party data: minecraft-data

`schemas/versions/` is generated by `bml import-versions` from ProtoDef protocol descriptions published in
[PrismarineJS/minecraft-data](https://github.com/PrismarineJS/minecraft-data); the 26.2 and 26.3 files come
from forks of it (`0xmthan/minecraft-data` and `DallasCarraher/minecraft-data`). The upstream
`pc/<version>/protocol.json` files are not stored in this repository: `scripts/fetch_minecraft_data.py`
downloads them, byte for byte, into `data/minecraft-data/pc/` (untracked) and checks each against the
repository, commit, upstream path and SHA-256 recorded in `scripts/minecraft_data_sources.json`.
`schemas/versions/manifest.json` records which protocol number each one describes.

Upstream states its licence in the README (`## License`, there is no LICENSE file):

> MIT
>
> Some of the data was extracted manually or automatically from wiki.vg and
> minecraft.gamepedia.com. If required by one of the sources the license might change to
> something more appropriate.

Regenerate the schemas with `bml import-versions`; do not hand-edit the generated files, change
`schemas/versions/manifest.json` or the importer instead.
