# BPS shared version declarations (sub-project A) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this
> plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 39 self-contained generated schemas in `schemas/versions/` with thin roots
plus generated shared files under `schemas/versions/common/`, so each distinct declaration is
stored once per set of versions in which it and everything it references is identical.

**Architecture:** `render::import` stays the definition of a version's text. A new
`protodef/share.rs` splits each rendered text into declarations (brace-counting scanner + safety
net), assigns each declaration an identity id by interning `(kind, name, text, sorted ids of
references)` over the per-version reference graph's SCCs, groups ids by the set of versions they
occur in (one file per set), and emits the layout. `versions::import_versions` writes or checks
the whole tree and removes orphaned `common/` files.

**Tech Stack:** Rust (existing `crates/bytemill`), no new dependencies, no language/loader/interpreter/
emitter changes.

**Spec:** `docs/superpowers/specs/2026-10-13-bps-shared-version-declarations-design.md`

## Global Constraints

- Invariant (spec §1): for every version, bytes and decoded JSON stay identical — against the
  single-file rendering, the hand-written `schemas/minecraft_26_3*.bps`, and the emitted rstom Rust.
- No language, loader, interpreter, or emitter changes; hand-written schemas untouched (spec §2).
- Output is pure and deterministic: ordered maps only (`BTreeMap`/`BTreeSet`), no hash-iteration
  order in any generated file (spec §4.5).
- `render::import` remains the single source of truth for a version's text (spec §4.2). Plan
  deviation from spec §4.5: no `Pieces` refactor of `render` — `share::split(render::import(..))`
  is the piece source, and the safety net (§4.2) plus the AST-equality check below make a mis-split
  an import failure, not silent corruption.
- Clippy `-D warnings` is a hard gate (pre-commit hook). Cargo/Python/Node run under the memory
  cap: `scripts/bytemill_cargo.sh`.
- `--only N` is removed from `import-versions`; the layout depends on every version (spec §4.5).
- Python (`bps/`) is NOT touched: it has no importer (spec §4.6).

```rust
/// A declaration kind; `Encoding` sorts before `Packet`.
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub enum Kind { Encoding, Packet }

/// One declaration: kind, name, and its text — doc comment lines directly above it
/// (divider comments `// ---` excluded) plus the declaration through its closing brace,
/// or its single line when it has none. `refs` holds the names it references that are
/// neither bare primitives nor packet routes: type references and spreads.
#[derive(Debug, Clone)]
pub struct Decl {
    pub kind: Kind,
    pub name: String,
    pub text: String,
    pub refs: Vec<String>,
}

/// One rendered version split into its parts.
pub struct Split {
    /// Everything before the first `import` line (title, GENERATED, patches, note), with the
    /// trailing blank line.
    pub header: String,
    /// The `import` lines before the declarations, verbatim (the two `../std/…` lines).
    pub imports: Vec<String>,
    pub decls: Vec<Decl>,
    /// From the first `protocol ` line at column 0 through the final `}`.
    pub protocol_block: String,
}

/// Split one rendered single-file text. The safety net: each piece must parse as exactly one
/// declaration of the expected kind and name; the pieces' (kind, name) sequence must equal the
/// whole text's; and each piece's parsed declaration must equal (AST `PartialEq`) the whole
/// text's declaration of that name. Any mismatch is an import failure.
pub fn split(text: &str) -> Res<Split>;
```

```rust
//! Sharing declarations across the generated protocol versions (spec
//! docs/superpowers/specs/2026-10-13-bps-shared-version-declarations-design.md):
//! split each rendered single-file text, assign every declaration an identity that includes
//! what it references, group identical declarations by the set of versions they occur in,
//! and assemble the root + shared-file layout.

use std::collections::BTreeMap;
use std::path::{Path, PathBuf};

use super::model::Res;

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub enum Kind { Encoding, Packet }

impl Kind {
    /// The column-0 keyword that starts a declaration of this kind.
    fn keyword(self) -> &'static str {
        match self {
            Kind::Encoding => "encoding ",
            Kind::Packet => "packet ",
        }
    }
    fn parse(keyword: &str) -> Option<Kind> {
        match keyword {
            "encoding " => Some(Kind::Encoding),
            "packet " => Some(Kind::Packet),
            _ => None,
        }
    }
}

#[derive(Debug, Clone)]
pub struct Decl {
    pub kind: Kind,
    pub name: String,
    pub text: String,
    pub refs: Vec<String>,
}

pub struct Split {
    pub header: String,
    pub imports: Vec<String>,
    pub decls: Vec<Decl>,
    pub protocol_block: String,
}

/// A line's role in the scan.
enum Line {
    /// `//` comment, not a `// ---` divider.
    Comment(String),
    Divider,
    /// `encoding `/`packet ` at column 0; the rest of the line after the keyword.
    DeclStart(Kind, String),
    /// `import "…"`
    Import(String),
    /// `protocol …` at column 0.
    Protocol,
    Other,
}

fn classify(line: &str) -> Line {
    let trimmed = line.trim_end(); // keep leading spaces: column-0 check below
    if let Some(rest) = trimmed.strip_prefix("//") {
        if trimmed.starts_with("// ---") {
            return Line::Divider;
        }
        return Line::Comment(trimmed.to_string());
    }
    if !line.starts_with("//") {
        // Column-0 keywords only (a comment line already returned).
        if let Some(kind) = [Kind::Encoding, Kind::Packet].into_iter().find_map(|k| {
            line.strip_prefix(k.keyword()).map(|rest| (k, rest))
        }) {
            return Line::DeclStart(kind.0, kind.1.to_string());
        }
        if let Some(rest) = line.strip_prefix("import \"") {
            if let Some(path) = rest.strip_suffix("\"") {
                return Line::Import(path.to_string());
            }
        }
        if line.starts_with("protocol ") {
            return Line::Protocol;
        }
    }
    Line::Other
}
```

Wait — the divider rule and blank lines: doc lines are the contiguous `Comment` lines directly

```rust
fn split(text: &str) -> Res<Split> {
    let mut header = String::new();
    let mut imports = Vec::new();
    let mut decls: Vec<Decl> = Vec::new();
    let mut protocol_block = String::new();
    let mut pending_doc: Vec<String> = Vec::new(); // comments since the last blank/decl line
    let mut lines = text.lines().peekable();
    let mut in_protocol = false;
    while let Some(line) = lines.next() {
        match classify(line) {
            Line::Protocol => {
                in_protocol = true;
                protocol_block.push_str(line);
                protocol_block.push('\n');
                for rest in lines {
                    protocol_block.push_str(rest);
                    protocol_block.push('\n');
                }
                break;
            }
            Line::Import(path) if !in_protocol => {
                if decls.is_empty() && pending_doc.is_empty() {
                    header.push_str(line); // an import after comments: keep order stable
                    header.push('\n');
                }
                imports.push(path);
                pending_doc.clear();
            }
            Line::Comment(c) if !in_protocol => pending_doc.push(c.to_string()),
            Line::Divider if !in_protocol => {
                pending_doc.clear(); // dividers are not doc comments
                // keep the divider in no piece; it is a section banner
            }
            Line::DeclStart(kind, rest) if !in_protocol => {
                let name = decl_name(kind, rest)?; // up to ` =`, ` {`, or ` {`
                let mut piece = String::new();
                for c in &pending_doc {
                    piece.push_str(c);
                    piece.push('\n');
                }
                pending_doc.clear();
                piece.push_str(line);
                piece.push('\n');
                // Consume lines until braces balance (outside comments and string literals).
                let mut depth = brace_delta(line)?;
                while depth > 0 {
                    let next = lines.next().ok_or_else(|| {
                        format!("declaration {name} ends before its closing brace")
                    })?;
                    depth += brace_delta(next)?;
                    piece.push_str(next);
                    piece.push('\n');
                }
                decls.push(Decl { kind, name, refs: Vec::new(), text: piece });
            }
            Line::Other if !in_protocol => {
                if line.trim().is_empty() {
                    pending_doc.clear(); // a blank line ends the doc-comment run
                } else if decls.is_empty() && imports.is_empty() {
                    header.push_str(line);
                    header.push('\n');
                } else {
                    return Err(format!("unexpected line between declarations: {line:?}"));
                }
            }
            _ => {}
        }
    }
    // ... safety net (Step 4) and refs (Task 2) fill decls.refs; see below.
    Ok(Split { header, imports, decls, protocol_block })
}

/// `uuid = {` / `keep_alive {` / `angle = f32;` -> the name.
fn decl_name(kind: Kind, rest: &str) -> Res<String> {
    let name = rest
        .split_once(" =")
        .or_else(|| rest.split_once(" {"))
        .map(|(n, _)| n.trim().to_string())
        .unwrap_or_else(|| rest.trim().to_string());
    if name.is_empty() || name.contains(|c: char| !c.is_ascii_alphanumeric() && c != '_') {
        return Err(format!("bad {} name {name:?}", kind.keyword().trim()));
    }
    Ok(name)
}

/// Brace balance of one line, ignoring braces in `//` comments and in `"…"` strings.
fn brace_delta(line: &str) -> Res<i32> {
    let mut depth = 0i32;
    let mut chars = line.chars().peekable();
    while let Some(c) = chars.next() {
        match c {
            '"' => {
                while let Some(c) = chars.next() {
                    if c == '\\' {
                        chars.next();
                    } else if c == '"' {
                        break;
                    }
                }
            }
            '/' if chars.peek() == Some(&'/') => break,
            '{' => depth += 1,
            '}' => depth -= 1,
            _ => {}
        }
    }
    Ok(depth)
}
```

The piece texts are then checked by the safety net before `split` returns:

```rust
fn check_pieces(text: &str, s: &Split) -> Res<()> {
    let whole = crate::parse(text).map_err(|e| format!("the rendered text does not parse: {e}"))?;
    if whole.enums.len() != 0 || whole.protocols.len() != 1 {
        return Err("the rendered text must hold exactly one protocol block".to_string());
    }
    let mut whole_decls: BTreeMap<(Kind, &str), String> = BTreeMap::new();
    for e in &whole.encodings {
        if whole_decls.insert((Kind::Encoding, &e.name), e.name.clone()).is_some() {
            return Err(format!("duplicate encoding {}", e.name));
        }
    }
    for p in &whole.packets {
        if whole_decls.insert((Kind::Packet, &p.name), p.name.clone()).is_some() {
            return Err(format!("duplicate packet {}", p.name));
        }
    }
    let seen: Vec<(Kind, &str)> = s.decls.iter().map(|d| (d.kind, d.name.as_str())).collect();
    let want: Vec<(Kind, &str)> = whole
        .encodings
        .iter()
        .map(|e| (Kind::Encoding, e.name.as_str()))
        .chain(whole.packets.iter().map(|p| (Kind::Packet, p.name.as_str())))
        .collect();
    if seen != want {
        return Err(format!(
            "the split found {} declarations but the text holds {}: {want:?}",
            seen.len(),
            want.len()
        ));
    }
    // Each piece: exactly one declaration, right kind and name, AST-equal to the whole text's.
    for d in &s.decls {
        let parsed = crate::parse(&d.text).map_err(|e| format!("{} {name}: {e}", d.kind.keyword().trim(), name = d.name))?;
        let piece_decls = match d.kind {
            Kind::Encoding => parsed.encodings.len(),
            Kind::Packet => parsed.packets.len(),
        };
        if piece_decls != 1
            || !parsed.enums.is_empty()
            || !parsed.protocols.is_empty()
            || parsed.encodings.first().map(|e| e.name.as_str()) != Some(d.name.as_str()).filter(|_| d.kind == Kind::Encoding)
            || parsed.packets.first().map(|p| p.name.as_str()) != Some(d.name.as_str()).filter(|_| d.kind == Kind::Packet)
        {
            return Err(format!(
                "{} {} does not split into exactly one declaration of that name",
                d.kind.keyword().trim(),
                d.name
            ));
        }
        let equal = match d.kind {
            Kind::Encoding => parsed.encodings[0] == whole.encodings.iter().find(|e| e.name == d.name).unwrap(),
            Kind::Packet => parsed.packets[0] == whole.packets.iter().find(|p| p.name == d.name).unwrap(),
        };
        if !equal {
            return Err(format!("{} {} splits to a different declaration", d.kind.keyword().trim(), d.name));
        }
    }
    Ok(())
}
```

```rust
impl Decl {
    fn fill_refs(&mut self) -> Res<()> {
        let parsed = crate::parse(&self.text)
            .map_err(|e| format!("{} {}: {e}", self.kind.keyword().trim(), self.name))?;
        let mut schema = crate::ast::Schema::default();
        match self.kind {
            Kind::Encoding => schema.encodings = parsed.encodings,
            Kind::Packet => schema.packets = parsed.packets,
        }
        let mut names = std::collections::BTreeSet::new();
        for r in crate::refs::references(&schema) {
            if r.kind == crate::refs::RefKind::Packet || crate::primitives::is_bare_primitive(&r.name) {
                continue;
            }
            names.insert(r.name);
        }
        self.refs = names.into_iter().collect();
        Ok(())
    }
}
```

`identity` — per version, Tarjan's SCC (iterative, explicit stack) over nodes `(Kind, String)`;
children first; intern keys:

```rust
pub type Id = u32;

pub fn identity(versions: &[Vec<Decl>]) -> Res<Vec<BTreeMap<(Kind, String), Id>>> {
    #[derive(Default)]
    struct Interner {
        ids: BTreeMap<String, Id>,
        next: Id,
    }
    impl Interner {
        fn get(&mut self, key: String) -> Id {
            let next = self.next;
            *self.ids.entry(key).or_insert_with(|| { self.next += 1; next })
        }
        fn len(&self) -> usize { self.ids.len() }
    }

    // Node tables and per-version edges.
    let mut intern = Interner::default();
    let mut out = Vec::with_capacity(versions.len());
    for decls in versions {
        let index: BTreeMap<(Kind, String), usize> = decls
            .iter()
            .enumerate()
            .map(|(i, d)| ((d.kind, d.name.clone()), i))
            .collect();
        // Tarjan, iterative; children (referenced nodes) finish first.
        // ... standard iterative Tarjan over `index`, edges = d.refs resolved through
        // `index`, dropping names absent from this version (external/std names).
        // For each SCC in discovery order (which yields children first for the condensation):
        //   singleton without self-loop:
        //       key = format!("d\0{}\0{}\0{}\0{}", kind, name, text, ids_sorted.join(","))
        //   component (multi or self-loop):
        //       members sorted by (kind, name, text); outside ids sorted;
        //       ckey = format!("c\0{}\0{}", members joined by "\u{1}", outside joined ",");
        //       cid = intern.get(ckey);
        //       member key = format!("m\0{cid}\0{}\0{}", kind, name) -> that member's id
        //   record id per (kind, name) in the version's map.
        // Pop order of Tarjan gives components children-first; iterate components in the
        // order they were popped.
    }
    Ok(out)
}
```

(The full Tarjan implementation is written out in the task; the skeleton above fixes the key
formats and the children-first requirement. All sorted lists are `BTreeSet`/sorted `Vec`.)

```rust
        // exactly one on each side, compared whole.
        let enc = |s: &bytemill::ast::Schema| -> std::collections::BTreeMap<&str, &bytemill::ast::EncodingDecl> {
            s.encodings.iter().map(|e| (e.name.as_str(), e)).collect()
        };

            s.enums.iter().map(|e| (e.name.as_str(), e)).collect()
```
