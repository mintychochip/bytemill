# BPS generates rstom's packet layer: waves 0-1 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** `bps emit rstom-tree` generates the first 64 packets of `rstom`'s hand packet tree in
place, with the hand API, and every id-table entry is pinned to BPS reference bytes.

**Architecture:** A shape ledger in `protoc` (`targets/rstom/shapes/`) records the hand API of each
swapped packet. The emitter combines a shape with the BPS wire body to write the packet file at
its hand path inside the `rstom` worktree, and writes one pin gate (`bps_wire_pins.rs` +
`wire_pins.json`) covering all 260 id-table entries. Wave 0 builds the tools and the gate and
triages every hand-vs-BPS difference; wave 1 swaps the packets whose shapes already match.

**Tech Stack:** Python 3.11 stdlib (`protoc`), Rust 2024 + `rustfmt` (`rstom`), cargo under the
constraints below.

**Spec:** `docs/superpowers/specs/2026-10-11-bps-generates-rstom-packets-design.md`

## Global Constraints

- `protoc` is Python 3.11+, **stdlib only**. Tests: `python -m pytest -q -p no:cacheprovider`.
- `protoc` commits go to `master`; `rstom` commits go to branch `bps-packets` in the worktree
  `/home/jlo/dev/rstom-bps`. **Never** edit `/home/jlo/dev/rstom` (a live benchmark loop owns it)
  or use `/home/jlo/dev/rstom/target`. Nothing is merged or pushed.
- Every heavy cargo/rustc run goes through `scripts/rstom_cargo.sh` (Task 1): `nice -n 19
  ionice -c3`, `CARGO_BUILD_JOBS=4`, `CARGO_TARGET_DIR=/dev/shm/rstom-bps-target`,
  `CARGO_PROFILE_DEV_DEBUG=0`, `CARGO_INCREMENTAL=0`. `/home` has ~13 GB free: never build there.
  Only one cargo run at a time; subagents write code and Python tests but do not run cargo.
- Generated Rust: first line `//! Generated by \`bps emit rust\``, `rustfmt --edition 2024`, every
  file under 400 lines, clippy-clean under `-D warnings`.
- Wave 1 edits **no** caller, test, plugin or machinery file in `rstom`.
- Triage categories (exact strings): `bps-bug`, `hand-bug`, `minestom-deviation`,
  `synth-artifact`, `domain-limit`.
- The class table is read from `<workspace>/tools/packets_gen/schema/packets.json`.

The gate (`PINS_TEST_RS`, emitted as `crates/rstom/tests/bps_wire_pins.rs`):

```rust
//! Generated by `bps emit rust`: every id-table entry pinned to BPS reference bytes.
//!
//! `bps/synth.py` builds a synthetic value of each packet, the BPS interpreter (verified
//! against vanilla 26.3) writes it, and the serializer the live registry holds for that id
//! must read every byte and write the same bytes back. Rows that differ are reported together.
//! `tests/bps/wire_pins_known.json` lists the triaged ones; an entry whose row passes is stale.

use std::collections::BTreeSet;
use std::panic::{AssertUnwindSafe, catch_unwind};

use rstom::network::buffer::NetworkBuffer;
use rstom::network::packet::packet_registry::PacketRegistry;
use rstom::network::packet::packet_vanilla as vanilla;
use serde::Deserialize;

#[derive(Deserialize)]
struct Pins {
    rows: Vec<Row>,
}

#[derive(Deserialize)]
struct Row {
    side: String,
    state: String,
    id: i32,
    class: String,
    hex: String,
}

#[derive(Deserialize)]
struct Known {
    side: String,
    state: String,
    id: i32,
    category: String,
    reason: String,
}

fn registry(side: &str, state: &str) -> &'static PacketRegistry {
    match (side, state) {
        ("CLIENT", "HANDSHAKE") => vanilla::client_handshake_registry(),
        ("CLIENT", "STATUS") => vanilla::client_status_registry(),
        ("CLIENT", "LOGIN") => vanilla::client_login_registry(),
        ("CLIENT", "CONFIGURATION") => vanilla::client_configuration_registry(),
        ("CLIENT", "PLAY") => vanilla::client_play_registry(),
        ("SERVER", "HANDSHAKE") => vanilla::server_handshake_registry(),
        ("SERVER", "STATUS") => vanilla::server_status_registry(),
        ("SERVER", "LOGIN") => vanilla::server_login_registry(),
        ("SERVER", "CONFIGURATION") => vanilla::server_configuration_registry(),
        ("SERVER", "PLAY") => vanilla::server_play_registry(),
        _ => panic!("unknown registry {side} {state}"),
    }
}

fn check(row: &Row) -> Result<(), String> {
    let info = registry(&row.side, &row.state)
        .packet_info(row.id)
        .map_err(|e| format!("no entry: {e:?}"))?;
    if info.simple_class_name() != row.class {
        return Err(format!("the table has {} here", info.simple_class_name()));
    }
    let bytes = hex::decode(&row.hex).expect("pin hex");
    let end = bytes.len() as i64;
    let mut buffer = NetworkBuffer::wrap(bytes.clone(), 0, end);
    let value = catch_unwind(AssertUnwindSafe(|| info.serializer.read(&mut buffer)))
        .map_err(|_| "read panicked".to_string())?;
    if buffer.read_index() != end {
        return Err(format!("read {} of {end} bytes", buffer.read_index()));
    }
    let written = catch_unwind(AssertUnwindSafe(|| {
        NetworkBuffer::make_array(|out| info.serializer.write(out, &value))
    }))
    .map_err(|_| "write panicked".to_string())?;
    if written != bytes {
        let at = written.iter().zip(&bytes).position(|(a, b)| a != b).unwrap_or(written.len().min(bytes.len()));
        return Err(format!("wrote {} bytes, pinned {}, first difference at {at}", written.len(), bytes.len()));
    }
    Ok(())
}

#[test]
fn every_id_table_entry_matches_its_bps_pin() {
    let dir = concat!(env!("CARGO_MANIFEST_DIR"), "/tests/bps");
    let pins: Pins = serde_json::from_str(&std::fs::read_to_string(format!("{dir}/wire_pins.json")).unwrap()).unwrap();
    let known: Vec<Known> = serde_json::from_str(&std::fs::read_to_string(format!("{dir}/wire_pins_known.json")).unwrap()).unwrap();
    let key = |s: &str, st: &str, id: i32| format!("{s}/{st}/{id}");
    let known_keys: BTreeSet<String> = known.iter().map(|k| key(&k.side, &k.state, k.id)).collect();

    std::panic::set_hook(Box::new(|_| {}));
    let mut unexpected = Vec::new();
    let mut stale = Vec::new();
    for row in &pins.rows {
        let k = key(&row.side, &row.state, row.id);
        match (check(row), known_keys.contains(&k)) {
            (Err(why), false) => unexpected.push(format!("{k} {}: {why}", row.class)),
            (Ok(()), true) => stale.push(format!("{k} {} passes: remove it from wire_pins_known.json", row.class)),
            _ => {}
        }
    }
    let _ = std::panic::take_hook();
    assert!(known.iter().all(|k| !k.category.is_empty() && !k.reason.is_empty()), "every known entry needs a category and a reason");
    assert!(unexpected.is_empty() && stale.is_empty(), "\nunexpected differences ({}):\n{}\nstale entries ({}):\n{}", unexpected.len(), unexpected.join("\n"), stale.len(), stale.join("\n"));
}
```

### Task 5: Shape model, extractor and report

**Files:** Create `bps/shapes.py`, `tests/test_shapes.py`; modify `bps/cli.py`.

**Interfaces:**

```python
@dataclass(frozen=True)
class FieldShape: name: str; type: str; docs: tuple[str, ...]
@dataclass(frozen=True)
class NewShape: present: bool; const: bool; must_use: bool; attrs: tuple[str, ...]; docs: tuple[str, ...]  # attrs: other `#[...]` lines on `new`, verbatim (e.g. `#[allow(clippy::fn_params_excessive_bools)]`)
@dataclass(frozen=True)
class SerializerShape: style: str; name: str; public: bool; docs: tuple[str, ...]  # style: "struct"|"constant"
@dataclass(frozen=True)
class Shape:
    cls: str; module: str; module_docs: tuple[str, ...]; struct_docs: tuple[str, ...]
    derives: tuple[str, ...]; form: str                      # "braced" | "unit"
    fields: tuple[FieldShape, ...]; new: NewShape
    serializer_fn_docs: tuple[str, ...]; serializer_fn_must_use: bool
    serializer: SerializerShape; extras: str | None          # "<stem>.ext.rs"
class ShapeError(Exception): ...
def shape_to_json(s: Shape) -> str; def shape_from_json(text: str) -> Shape
def extract_shape(source: str, cls: str, module: str) -> Shape       # hand file text -> Shape
def load_ledger(dir: Path) -> dict[str, Shape]                       # keyed by module
def mismatch(shape: Shape, bps_fields: list[tuple[str, str]]) -> list[str]   # [] when eligible
```

The JSON nests as spec 4.1 (`struct`, `new`, `serializer_fn`, `serializer_struct`); the dataclasses
are flat. `extract_shape` reads the text before the first `#[cfg(test)]`. It takes the leading `//!` lines
as `module_docs` (dropping a `Generated by` banner), the `///` lines and `#[derive(...)]` above
`pub struct <cls>`, the fields of a braced struct (`pub name: Type,` with its docs; balanced `<>`),
the `new` and `serializer` items of `impl <cls>` (docs, `#[must_use]`, `const`), the serializer
style from the body (`Arc::new(<X>Serializer)` => `struct`, `Arc::new(ConstantSerializer::new(` =>
`constant`) and the serializer struct's docs and `pub`. Any other `pub fn`/`const` in an inherent
impl sets `extras`. It raises `ShapeError` (naming the construct) for another attribute than
`derive`, an `impl Default/From/...` for the class, a free function, or another public type.

//!
//! Port of `net.minestom.server.network.packet.client.common.ClientKeepAlivePacket`.

use crate::network::buffer::NetworkBuffer;
use crate::network::packet::client::client_packet::{ClientPacket, ClientPacketGroup};
use crate::network::packet::packet::Packet;
use crate::network::packet::serializer::{PacketSerializer, PacketValue, downcast};
use crate::network::types::LONG;

/// Java: `record ClientKeepAlivePacket(long id) implements
/// ClientPacket.Configuration, Play` — the answer to
/// [`KeepAlivePacket`](crate::network::packet::server::common::keep_alive_packet::KeepAlivePacket).
#[derive(Copy, Clone, Debug, PartialEq, Eq)]
pub struct ClientKeepAlivePacket {
    /// Java: `id()`.
    pub id: i64,
}

impl ClientKeepAlivePacket {
    /// Java: `new ClientKeepAlivePacket(long)`.
    #[must_use]
    pub fn new(id: i64) -> Self {
        Self { id }
    }

    /// Java: `ClientKeepAlivePacket.SERIALIZER`.
