# BPS generates rstom's packets: wave 2 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** `emit rstom-tree` generates the 46 hand packets whose fields map one-to-one onto BPS
wire fields (renames, reorders, elided counts and presence flags), keeps their hand API, and
carries their items and inline tests into sibling files.

**Architecture:** The shape ledger gains per-field wire bindings, `new` parameters, imports,
hooks and accepted-audit records. `_packet_body` takes a `Projection` that maps wire identifiers
to hand-struct expressions, so the in-tree template reuses the wire body. A split engine moves
every non-API item of a hand file to `<stem>.ext.rs` and its tests to `<stem>.tests.rs`, and a
conservation check proves nothing is lost. A fail-closed audit lists the non-wire behaviour of
each hand serializer.

**Tech Stack:** Python 3.11 stdlib (`protoc`), Rust 2024 + nightly `rustfmt` (`rstom`), cargo
under the constraints below.

**Spec:** `docs/superpowers/specs/2026-10-12-bps-generates-rstom-packets-waves-2-5-design.md`
(builds on `2026-10-11-bps-generates-rstom-packets-design.md`).

### Task 4: Binding inference, the serializer audit and the worklist

**Files:** Create `bps/shapes/infer.py`, `tests/test_infer.py`; modify `bps/shapes/ledger.py`,
`bps/cli.py`.

**Interfaces:**
- Produces (`infer.py`): `hand_write_order(src, cls, field_names) -> list[str]` (the order in
  which the hand serializer's `write` body mentions the fields through `packet.`, `value.`, `p.`
  or `self.`; fields it never mentions are omitted); `Inference(fields, counts, flags,
  unresolved_hand, unresolved_wire, review)` as in the spec 3.3; `infer_bindings(shape, wire,
  write_order) -> Inference`; `Finding(id, where, line, kind)` and `audit_serializer(src, cls) ->
  list[Finding]`.
- Inference rules: derived wire fields are the count of a bound counted list and the flag of a
  bound guarded `Option` (a bare identifier guard). Pass 1 binds a hand field to the wire field
  of the same name and an equal type. Pass 2 walks the remaining hand fields in write order
  (declaration order when the write mentions none) against the remaining non-derived wire fields
  in wire order and binds them when the types are equal after normalisation; otherwise the hand
  field is unresolved with the reason `type: hand <T> vs wire <U>`. A pass-2 binding with two or
  more candidates of that wire type is added to `review`.
- Audit rules: scan the hand `write` and `read` bodies (the text of `fn write` and `fn read` in
  the serializer impl). A line is a **finding** when it contains `panic!`, `assert!`,
  `assert_eq!`, `debug_assert!`, `unreachable!`, `.expect(`, `unwrap_or_else`, an identifier that
  starts with `MAX_`, `.list(`, `.set(`, `read_size(`, `clamp(` or `?`. Benign idioms are not
  findings: `size.max(0)` over a count, `i32::try_from(<x>.len()).expect("list length fits an
  int")`, `downcast::<..>`, `Box::new(..)`. `kind` is `assert`, `panic`, `limit`, `clamp`, `convert`
  or `other`.
- Produces (`ledger.py`): `packet_report` returns for each hand packet one of `swapped`,
  `bindable`, `bindable; audit: <n>` or `blocked: <reason>`. `bindable` needs a shape, a complete
  inference (no unresolved hand or wire field) and equal types after normalisation.
- Produces (`cli.py`): `shapes extract --bindable` (extract every bindable packet; the ledger
  JSON carries the inferred `wire` attributes), `shapes audit <schemas> --rstom <ws> [--class C]`
  (prints `Class<TAB>id<TAB>kind<TAB>line`), and `shapes report` with the new statuses.

**Files:** Create `bps/shapes/split.py`, `tests/test_split.py`, `tests/test_emit_tree_v2.py`;

**Interfaces:**
- Produces (`split.py`): `Split(ext: str | None, tests: str | None)`; `split_hand_file(src, shape)
  -> Split`: the ext text is `//! Hand-written items of <Class>.` + `use super::*;` + the `use`
  lines the moved text needs + every top-level item other than the generated ones + one inherent
  impl block holding the members of the packet struct's impl other than `new` and `serializer`;
